Penghapusan Data

Informasi tentang penghapusan data pengguna

Chef Genius berkomitmen untuk melindungi privasi Anda. Halaman ini menjelaskan bagaimana kami menangani permintaan penghapusan data.

Cara Meminta Penghapusan Data

Anda dapat menghapus data Anda dengan dua cara:

Opsi 1: Dari Dalam Aplikasi

  1. Buka aplikasi ChefGenius
  2. Pergi ke Profil → Pengaturan
  3. Pilih "Hapus Akun"
  4. Konfirmasi penghapusan

Opsi 2: Hubungi Kami

Kirim permintaan ke:

  • 📧 Instagram: @inceiqbal
  • 📱 WhatsApp: 087845245720

Data yang Dihapus

Ketika Anda menghapus akun, data berikut akan dihapus secara permanen:

  • Informasi profil (nama, email, foto)
  • Data pantry dan shopping list
  • Resep favorit
  • Riwayat masak dan level XP
  • Postingan dan komentar di komunitas Inzara

Waktu Pemrosesan

Penghapusan data dari dalam aplikasi diproses langsung (realtime). Untuk permintaan manual via kontak, kami akan memproses dalam 7 hari kerja.
